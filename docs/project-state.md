## プロジェクト概要

建設業の一人親方・小規模事業者向け資金繰り／ファクタリング比較 LP。目標は広告費を投じても継続的に利益が残ること。見た目やクリック数のみで収益改善と判断しない。

静的 HTML/CSS/JavaScript、GitHub Pages、公開ドメイン shikin.diggworks.com。パッケージインストール／ビルド不要。実装は index.html、assets/config.js、assets/analytics.js。詳細ルールは [AGENTS.md](../AGENTS.md)。

## 事業上の決定事項

- 固定コピー「仕事はある。売上もある。でも、入金はまだ先。」と青・白・黄色、建設現場の文脈を維持。理由のない全面改修をしない。
- 事業形態選択は説明の後。候補数は固定せず、対象適合性と確認済み条件で比較する。旧資料の No.1 固定構成に戻さない。
- 根拠のない順位・料金・審査率・実績を掲載しない。商用条件は案件ごとに確認する。
- 主指標は確定報酬−広告費−変動費。運営費・税金控除後の利益とは区別する。詳細は既存の計測文書を参照。
- 広告開始・課金は明示承認後。1万円は [広告テスト案](ad-test-plan.md)であり承認済み予算ではない。
- 公開・マージはその作業の承認範囲を確認する。今回の文書整備には公開変更を含まない。
