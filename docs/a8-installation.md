状態: 設置準備のみ、外部送客停止。実広告コードは未受領。会員向け情報や内部資料はこの文書に記載しない。

## 現在の設置枠

index.html の ququmo-affiliate-slot に案内ボタンと準備中の表示を置く。隣接する template#ququmo-a8-code は空の不活性領域で、スクリプトは中身をDOMへ展開しない。previewMode は true のまま。A8リンク・計測画像・広告スクリプトは現在のページに存在しない。

空の設置枠は広告掲載やASP連携の完了を意味しない。フラグをfalseにするだけで広告が有効になる実装にはしていない。

## 稼働前に必要な確認

1. 対象サイト・掲載面・媒体への掲載、具体的な検索広告経路、除外語・広告文・URL提出の要件を確認。提携承認だけで経路の許可としない。
2. 対象サイト用にA8が発行した広告コード一式を受領し、広告主・送客先・素材種別・必要な画像/スクリプトを確認。一般公式URLから広告URLを組み立てない。
3. 広告コードの改変可能範囲と計測画像の取り扱いをA8の最新公式案内または所定窓口で確認。今回の環境では公式ページが403で未確認。勝手に申請や問い合わせを送らない。
4. コード本文・リンクURL・画像URL・パラメータ・文言・属性・順序・サイズ・rel等を、許可未確認のまま編集しない。黄色CTAと両立する素材・表現を確認する。CSSでの外観変更も許可範囲を確認する。
5. コードに付属する計測画像はバナーと同一とは限らない。小さい/透明な画像でも削除・別画像への置換・遅延読込・URL短縮・プロキシ化を独断で行わない。外部通信となるため承認前の試作には読み込まない。
6. 実コードが得られたら原本と設置後の一式を照合し、画像を含む構成要素の欠落がないか確認する。自己申込・虚偽見積で成果テストをしない。

## 稼働化は別の変更

承認後の作業で案内ボタンと空templateを、許可された発行コード一式に置き換える。templateの自動展開は実装していない。許可のない追跡パラメータ追加や既定文言の差し替えはしない。コード非改変とGA4クリック取得を両立するため、必要なら親の設置枠にイベントを委譲し、広告コードそのものへdata属性を付けない方法をレビューする。

公開のPR表示・プライバシー・リンク属性を実際の素材と取扱いに合わせる。必要なrel属性追加等とコード非改変の扱いが競合する場合は、承認元に確認して解決し、独断で優先しない。

画像のリクエスト成功はクリック/申込/成果承認の証拠ではない。GA4の外部クリック、広告主到着、A8成果発生・承認を分離する。実コードの形式や到達保証を今回のテストから推測しない。

## 公開前チェック

- 許可、発行元、送客先、掲載面、URL提出、コード/画像の扱いが確認済み。
- 実コードを改変せず、コード一式を照合済み。実装時に個別のレビューを行う。
- 初回page_view 1回、内部操作・表示到達・外部クリックを分離。GA4本番受信とASPの検証可能範囲を確認。
- Cookie/外部送信、掲載主体、連絡先、費用・契約リスクの表示を実態に合わせる。
- スマホ幅、画像とリンクの動作、読込タイミングを確認。広告費・予算承認は別ゲート。

確認証跡は公開可能な要約だけを履歴へ残し、アカウント固有の条件や会員情報をGitHubへ転載しない。
